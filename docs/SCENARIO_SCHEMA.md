# Simulator schema and handoff migration

`proofmesh-sim-1` is strict JSON: unknown fields, duplicate object keys, trailing JSON, >4 MiB input, >10,000 events, decreasing/negative event times, unknown event names are errors. Times are integer seconds in [0,10^12]. Equal times preserve array order. CLI defaults to B3 freshness_budget=120, overridable with --budget; --strict is B2. All sources/targets/actions must match exact local rules and explicit federated domains. The initial bundles are both initial cache and authority; PUBLISH_NEW_BUNDLE updates authority only and FETCH_BUNDLE updates cache. ROTATE_ISSUER is a publication alias, not immediate cache installation. ISSUE_IDENTITY creates a descriptor, never a signature. REVOKE_ISSUER removes a synthetic issuer from the authoritative bundle, increments known sequence; it does not deliver a notice. EXPIRE_SVID updates a descriptor. CLOCK_SKEW is an absolute local offset; ADVANCE_CLOCK advances through its `at`. COMPROMISE_ISSUER records oracle compromise with no secret notification to verifier. DROP_BUNDLE_UPDATE records a skipped delivery. PARTITION/HEAL affect fetches. DENY_AUDIENCE is a local deny; REMOVE_FEDERATION removes exact relationship and cache. REQUEST_AUTH references named credential, claimed source, exact target/audience/action and request identifier. Duplicate request identifier rejects within this runner (not intrinsic X509-SVID replay protection). Labels never enter evaluation.

The handoff `research-example-0.1` file used inline issuer/source and ambiguous expected decision. Preserve original in the imported handoff zip; new `examples/federation_basic.scenario.json` uses declared credential and policy, explicit expiry/profile/signature simulation and schema version. Epoch is local policy metadata, not spiffe_sequence. All public key labels are synthetic fingerprints; descriptor SHA-256 is an audit hash, not a certificate fingerprint.

An identical signed bundle replay cannot establish freshness. The freshness observation trusts a genuinely fresh authenticated fetch (channel/session origin), not a replayed timestamp or signed content. Empty/removed issuer evidence remains REJECT even after aging. Unknown present bundle freshness is INDETERMINATE, not inferred remote revocation. No state persists across CLI invocations. Exported Store operations copy inputs/outputs; snapshots are per domain.
